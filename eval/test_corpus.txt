RAG (Retrieval-Augmented Generation) is an AI technique that combines information retrieval with text generation. Instead of relying solely on a model's training data, RAG retrieves relevant documents from a knowledge base and uses them as context for generating answers. This reduces hallucination because the model is constrained to information in the retrieved context rather than fabricating facts from memory.

Vector databases store text as numerical vectors called embeddings. An embedding is a high-dimensional array of numbers that captures the semantic meaning of a piece of text. Similar texts produce embeddings that are mathematically close together in vector space. pgvector is a PostgreSQL extension that adds vector storage and cosine similarity search, allowing semantic search directly inside a relational database.

Embeddings are created by passing text through an embedding model. The model outputs a fixed-size vector, for example 768 dimensions for nomic-embed-text. These vectors can be compared using cosine similarity: two vectors pointing in the same direction have a similarity of 1.0, and completely unrelated vectors approach 0.0. Ollama is a tool for running open-source embedding and language models locally without sending data to external APIs.

Hybrid search combines semantic vector search with traditional full-text keyword search. Reciprocal Rank Fusion (RRF) is an algorithm that merges the ranked result lists from both methods into a single ranked list. Each document receives a score of 1 divided by (k plus its rank) from each list it appears in, where k is typically 60. A document that ranks highly in both lists gets a higher combined score than one appearing in only one list. Hybrid search outperforms pure semantic or pure keyword search in most real-world retrieval tasks.

Chunking is the process of splitting a large document into smaller pieces before ingesting it into the vector database. Typical chunk sizes are between 200 and 500 words. Smaller chunks improve retrieval precision because each chunk contains a focused topic, but they may lose surrounding context. Larger chunks preserve more context but introduce noise because the retrieved chunk may contain irrelevant sentences alongside the relevant ones. A 50-word overlap between consecutive chunks prevents important information from being split across chunk boundaries.
